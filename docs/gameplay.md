# README gameplay animation

`gameplay.gif` is a 10-second excerpt of stage 100 from the gameplay video on
[todd.sh/StealthGame](https://www.todd.sh/StealthGame). The video was generated by
[`tools/host/capture.c`](../tools/host/capture.c), which runs the actual game code
with an autopilot and records its frames and synthesised audio.

The GIF is 368 × 448 at 12 FPS, beginning three seconds into the published
video. It is not a camera recording of the hardware. Re-encode a local copy of
the video with:

```bash
ffmpeg -ss 3 -t 10 -i stage100.mp4 \
  -filter_complex '[0:v]fps=12,scale=368:448:flags=neighbor,split[a][b];[a]palettegen=stats_mode=diff[p];[b][p]paletteuse=dither=none' \
  -loop 0 docs/gameplay.gif
```

The recorder's header documents how to rebuild the original frames and audio.
